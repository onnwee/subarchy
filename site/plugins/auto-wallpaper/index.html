Plugins / Auto wallpaper

Au

Auto wallpaper

Changes the wallpaper on a schedule.

Moves to the next image in a folder every 30 minutes on mains power and every hour on battery. On battery it waits unless you allow it. Click to change the image now.

However many bars show it, the wallpaper changes once.

Turn it on

It is off by default. Click the SUBCULT mark at the left of the bar, open Bar layout in Settings, add subcult.auto-wallpaper to a section and apply.

Or list it in ~/.config/subcult/shell/bar.json. A section you set there replaces the default list for that section, so give the whole list:

{
 "layout": {
  "right": [
   "subcult.keyboard-layout",
   "subcult.n8n",
   "subcult.tray",
   "subcult.audio",
   "subcult.display",
   "subcult.ht3",
   "subcult.bluetooth",
   "subcult.tailscale",
   "subcult.network",
   "subcult.notifications",
   "subcult.battery",
   "subcult.auto-wallpaper"
  ]
 }
}

Settings

Auto wallpaper settings
SettingDefaultMeans
directory"/usr/share/backgrounds/subarchy"The folder of images.
mode"sequential"sequential or shuffle.
onBatteryfalsetrue to keep changing on battery.

Set them under the plugin's id in ~/.config/subcult/shell/bar.json:

{
 "widgets": {
  "subcult.auto-wallpaper": {
   "directory": "/usr/share/backgrounds/subarchy"
  }
 }
}

No network. It contacts no servers.

Manifest

{
  "id": "subcult.auto-wallpaper",
  "name": "Auto wallpaper",
  "version": "1.0.0",
  "api": 0,
  "kind": "bar-widget",
  "cost": {
    "timers": [{ "name": "rotate", "ac": 1800, "battery": 3600 }]
  },
  "settings": {
    "directory": "/usr/share/backgrounds/subarchy",
    "mode": "sequential",
    "onBattery": false
  }
}
