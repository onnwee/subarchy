Subarchy / Plugins

Plugins

Every part of Subarchy's bar is a plugin: a small program with its own manifest, which states every timer it runs and every server it contacts. 26 plugins ship with the shell; 23 are in the bar from the start and the other 3 wait until you add them.

Make your own

A plugin is a folder in the shell's source with a manifest.json and a Widget.qml. Writing a plugin covers the contract; new plugins arrive as pull requests.
