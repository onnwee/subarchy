Plugins / Agents usage

Ag

Agents usage

How much of their limits your coding agents have used.

Reads the local usage files of Claude Code and Codex through subcult agent usage --json. The bar shows each agent's tightest limit, or its tokens today when it keeps no limits on disk; the panel has the rest.

Nothing goes over the network. It runs only while it is in the bar, and stays hidden until an agent has written files.

Turn it on

It is off by default. Click the SUBCULT mark at the left of the bar, open Bar layout in Settings, add subcult.agents to a section and apply.

Or list it in ~/.config/subcult/shell/bar.json. A section you set there replaces the default list for that section, so give the whole list:

{
 "layout": {
  "right": [
   "subcult.keyboard-layout",
   "subcult.n8n",
   "subcult.tray",
   "subcult.audio",
   "subcult.display",
   "subcult.ht3",
   "subcult.bluetooth",
   "subcult.tailscale",
   "subcult.network",
   "subcult.notifications",
   "subcult.battery",
   "subcult.agents"
  ]
 }
}

Settings

Agents usage settings
SettingDefaultMeans
agents["claude", "codex"]The agents to show, from claude and codex.

Set them under the plugin's id in ~/.config/subcult/shell/bar.json:

{
 "widgets": {
  "subcult.agents": {
   "agents": [
    "claude",
    "codex"
   ]
  }
 }
}
