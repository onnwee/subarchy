Install

There is no published image yet, so you build the ISO and install it into a virtual machine.

Requirements

What each step needs
StepNeeds
Build the ISOArch Linux, archiso, Go, Docker, sudo
Boot it in a VMqemu-base, edk2-ovmf
Install into a VMThe above, plus swtpm and imagemagick
Run itx86_64 with UEFI. The ISO does not boot in legacy BIOS mode.

Build the ISO

git clone https://github.com/subculture-collective/subarchy.git && cd subarchy
make iso

The image lands in build/iso/.

First build

On a fresh checkout make iso stops and names the packages Subarchy rebuilds itself. Build them, then run make iso again. How: Developers.

Try it in a VM

Test targets
RunDoes
make iso-testBoots the newest ISO in QEMU and checks it over the serial console
make install-testInstalls into a VM disk, then boots the result and checks it
make install-test-offlineThe same through the guided installer, with the network off

The installer

subarchy-setup starts by itself on the live ISO's first console. On a serial console or over SSH, run subarchy-setup.

The installer's screens, in order
ScreenNotes
Language
Keyboard layout
Wi-FiOnly without a wired connection and with a Wi-Fi card. Skipping it is safe: the install uses the package repository on the image.
DiskShows what is on each disk. You can open one read-only before choosing.
Computer name, user, password
Disk passphraseUnlocks the LUKS2 disk at boot. TPM unlock can replace it later.
Time zoneOpens on a guess. Online, the guess asks ipapi.co or ipwho.is, which sends them your public address.
SummaryEvery answer once more, under Does this look right?
EraseAsked last. The default is no.

Warning

The installer wipes the disk you choose. Do not point it at a disk you need.

Installer keys
EscBack one step, on every screen
LShow or hide the end of the log while it installs. The full log is /var/log/subarchy-install.log.

First login

Log in at the SDDM screen. The session is Hyprland. Then:

  • Super + Return opens a terminal, Super + Space the launcher. All keys: Keys.
  • subcult update brings the system up to date. See Updates and recovery.
  • sudo subcult disk tpm enable unlocks the disk with the TPM instead of the passphrase.

To install without questions, from a file, see Developers.
