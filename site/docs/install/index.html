Docs / Install

Install

Download the ISO, write it to a USB stick, boot it and answer the installer. The image carries its own packages, so the install needs no network.

Requirements

What you need
Computerx86_64 with UEFI. The ISO does not boot in legacy BIOS mode.
USB stickAt least as large as the ISO. Writing the image erases it.
DiskA whole disk for Subarchy. The installer wipes it.
NetworkOptional. With one, the installer can fetch newer packages from the stable channel.

Download

Get the newest subarchy-version-x86_64.iso and its SHA256SUMS file from the releases page (opens in a new tab). In the folder you saved them to, check the image:

sha256sum -c SHA256SUMS --ignore-missing

It should print the file name and OK. Anything else means a damaged download: fetch it again.

Write the USB stick

On Linux, find the stick with lsblk, then write the image to the whole device, not a partition:

sudo dd if=subarchy-version-x86_64.iso of=/dev/sdX bs=4M oflag=sync status=progress

Warning

dd erases whatever is at of=. Check the device name twice.

On Windows or macOS, any USB image writer works. In Rufus, choose DD image mode when it asks.

Boot it

  1. Turn Secure Boot off in the firmware settings, often under F2 or Del at power-on. You can turn it on again after the install, with keys made on your machine: see Secure Boot and TPM unlock.

  2. Pick the USB stick from the firmware's boot menu, often F12, F11 or Esc.

  3. Wait for the installer. It starts by itself on the first console.

In a virtual machine, choose UEFI firmware: OVMF in QEMU, Enable EFI in VirtualBox.

The installer

subarchy-setup asks its questions first and touches no disk until the last one. On a serial console or over SSH, start it with subarchy-setup.

The installer wipes the disk you choose. Do not point it at a disk you need.

Installer keys
EscBack one step, on every screen

While it installs, the installer detects the machine and applies its hardware fixes: firmware, drivers and settings for known laptops and parts. subcult hw fixes lists the ones your machine got.

First login

Remove the USB stick and reboot. Type the disk passphrase, then log in at the SDDM screen. The session is Hyprland.

  • Super + Return opens a terminal, Super + Space the launcher. All keys: Keys.
  • subcult update brings the system up to date. See Updates and recovery.
  • subcult setup fingerprint lets the lock screen take a touch, on supported readers.

Secure Boot and TPM unlock

Both are optional. Secure Boot uses keys made on your machine; TPM unlock then replaces the typed disk passphrase. TPM unlock needs Secure Boot on, because it trusts the boot only while the Secure Boot keys are unchanged.

  1. Put the firmware in setup mode. In its Secure Boot settings, choose Reset to setup mode or Clear keys, and leave Secure Boot itself off.

  2. Boot Subarchy and run sudo subcult secureboot setup. It makes the keys, signs the boot loader and kernels, and enrolls the keys alongside Microsoft's, which some graphics and network cards need.

  3. Reboot, turn Secure Boot on if the firmware did not, and check with subcult secureboot status.

  4. Run sudo subcult disk tpm enable. The next boot unlocks without the passphrase.

Kernel and boot loader updates are signed automatically after this.

Keep the passphrase

It stays the recovery key. A firmware update or reset can change or drop the Secure Boot keys; the disk then asks for the passphrase again. Run sudo subcult secureboot setup once more, or turn Secure Boot off to boot at all.
