Docs / Shell aliases

Shell aliases

zsh and bash load the same aliases and functions. An alias exists only when its tool is installed. Make zsh or bash your login shell with subcult shell set zsh.

Your own

Your ~/.zshrc or ~/.bashrc loads Subarchy's setup on its first line. Add aliases after it; a later alias with the same name wins.

Shell keys

Keys in the shell
Ctrl + RSearch history with atuin
UpThe shell's own history, one line at a time
Ctrl + TPick a file with fzf and paste its path
Alt + CPick a folder with fzf and go there
