Glossary

Short definitions, so the other pages can stay short. Links in the docs that look like this come here.

ABCEFHLMNOPQSTUWZ
Arch Linux Archive
Dated copies of the Arch package repositories. The stable channel points at one date, so every machine on it gets the same packages.
archiso
Arch's tool for building live ISO images. make iso uses it.
atuin
Shell history search, on Ctrl + R. Sync stays off unless you log in to a server.
AUR
The Arch User Repository: build recipes from users, not official packages. Subarchy rebuilds the few it needs from pinned sources.
btrfs
The root filesystem. It compresses with zstd and is split into subvolumes, which snapper snapshots.
Channel
Where updates come from: stable, a dated Arch Linux Archive snapshot, or edge, the mirrors. See Updates and recovery.
ESP
The EFI system partition: a small FAT32 partition the firmware boots from.
Font roles
Monospace, sans-serif and serif. Set one with subcult font set and every app that follows the role changes.
fzf
A fuzzy picker for files, folders and history in the terminal. Ctrl + T picks a file, Alt + C a folder.
Hyprland
The Wayland compositor: it draws windows and handles keys. Subarchy configures it in Lua.
Launcher
Super + Space. Finds apps and commands, and with a prefix also does maths, web search, files, emoji and clipboard history. See Keys.
Limine
The boot loader. It lists one boot entry per snapshot.
LUKS2
Linux disk encryption. The root partition is encrypted; you unlock it with a passphrase or the TPM.
Migrations
Scripts that bring an existing install in line with a newer Subarchy. subcult update runs the ones not yet run.
Nerd Font
A font patched with icon glyphs. subcult font patch makes a Nerd Font copy of a font you have.
OSD
On-screen display: the small box that shows volume, brightness or Caps Lock after a key press.
Palette
One set of named colours that the whole desktop reads. Pult writes it.
Palette role
One named colour in the palette, such as lavender. The cursor takes a role, not a hex value, so it follows theme changes.
Plymouth
The boot splash shown while the system starts.
polkit
Decides which privileged actions a user may take. Subarchy's shell draws its password dialog.
Pult
SUBCULT's theme tool. pult apply switches the theme. pult.subcult.tv (opens in a new tab)
Quickshell
The toolkit Subarchy's bar, notifications, launcher and lock screen are written in.
Scratchpad
A hidden workspace you show and hide over the current one with Super + S.
SDDM
The login screen.
Secure Boot
Firmware that boots only signed files. sudo subcult secureboot setup turns it on with keys made on your machine.
snapper
Takes and manages btrfs snapshots.
Snapshot
A read-only copy of the system at one moment. Boot one from the boot menu to go back to it. See Updates and recovery.
subarchy-setup
The guided installer on the live ISO. See Install.
subcult
The command that runs every subcult-* tool; sub for short. See Commands.
Tailnet
Your private Tailscale network. subcult tailscale send sends files to its machines.
TPM
A security chip on the mainboard. It can unlock the disk at boot instead of a typed passphrase: sudo subcult disk tpm enable.
UKI
Unified kernel image: the kernel, its initramfs and command line in one file. Subarchy makes one per kernel.
uwsm
Starts and stops the Hyprland session as systemd units, so logging out ends everything cleanly.
Worktree
A second checkout of a git repository in its own folder, on its own branch. ga makes one, gd removes it.
zoxide
Remembers the folders you visit. cd with part of a name goes to the best match.
zram
Compressed swap in memory.
