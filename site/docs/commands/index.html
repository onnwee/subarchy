Docs / Commands

Commands

subcult runs every subcult-* program on the path. sub is the same command, shorter.

Getting around
subcult commandsList every command, with its arguments
sub updateThe same as subcult update
TabCompletes commands and arguments in zsh and bash
Super + SpaceThe launcher runs commands too: type one and press Enter

In the tables, sudo means the command needs sudo, and asks first means it confirms before it changes anything. [--json] and the like are arguments; square brackets mean optional.

System and updates

System and updates commands
CommandDoes
subcult update [--yes] [--no-snapshot] [--dry-run]Update the system: snapshot, packages, migrations, cleanup sudo
subcult update check [--quiet]Count available package updates without installing them
subcult update migrate [--pending | --mark-all]Run pending migrations, or list them with --pending
subcult channelShow the update channel: stable (an Arch snapshot) or edge (the mirrors)
subcult channel set stable | edgeSwitch the update channel sudo
subcult system logoutLog out of the session asks first
subcult system rebootRestart the machine asks first
subcult system shutdownTurn the machine off asks first
subcult system suspendSuspend the machine; the session locks first
subcult lockLock the session with Subarchy's lock screen
subcult idleShow when the session locks, the display goes off and the machine suspends
subcult idle applyApply changed idle settings (restarts the idle service)
subcult idle configPrint the hypridle configuration made from the idle settings
subcult power auto [--dry-run]Set the power profile for the current power source

Look commands

subcult theme reloadReload what reads the theme after Pult applied one
subcult font check <family>Check whether a font works in the terminal and shell
subcult font currentShow the family behind each font role
subcult font import <files...>Add font files you own for your user
subcult font install <name>Install a curated font or any Nerd Font sudo
subcult font list [--all]List the curated fonts, what is installed and what each role uses
subcult font patch <family>Make a copy of a font with Nerd Font icons sudo
subcult font set <family> [--ui|--serif] [--force]Use a font for the terminal and shell (or --ui, --serif) sudo
subcult cursor applyRebuild the cursor in the chosen theme colour and apply it
subcult cursor set [--role <role>] [--size 24|32|48]Choose the cursor colour (a palette role) and size
subcult display profile apply [<name>] [--dry-run]Apply a saved layout (the matching one when no name is given)
subcult display profile listList the saved layouts and which one matches the connected monitors
subcult display profile remove <name>Forget a saved layout
subcult display profile save <name>Save the connected monitors' layout and workspaces under a name
subcult display scale <up|down|1..4>Set the focused display's scale, or step up or down through the preset scales
subcult screensaver render [--user] [--out DIR] [--palette FILE] [--captures DIR] [--size WxH] [--fps N] [--force]Render the screensaver loops from the recorded effects in the palette

Apps

Apps commands
CommandDoes

subcult app default [<role> [<id>]] [--dry-run]Show or set the default app per role
subcult app install <id>... [--dry-run]Install apps from the catalogue sudo
subcult app list [--role ROLE] [--json]List the app catalogue
subcult app remove <id>... [--dry-run]Remove apps installed from the catalogue sudo asks first
subcult app show <id> [--json]Show one app
subcult app validate [file]Check the system and user catalogue files
subcult app webapp install <name> <url> [--icon FILE] | remove <name>Open a site as an app (a Chromium app window with its own desktop entry)
subcult capture recording [--audio]Start or stop a screen recording to the Videos folder
subcult capture screenshot [region|window|output]Take a screenshot to the Pictures folder and the clipboard
subcult clipboard clearDrop the whole clipboard history
subcult clipboard copy <id>Put a history entry back on the clipboard
subcult clipboard list [--json]List the clipboard history, newest first
subcult clipboard remove <id>Drop one entry from the history
subcult clipboard show <id>Print a text entry, or the file holding an image entry
subcult calendar list [--json]Show the cached events
subcult calendar statusShow when the calendars last synced and how each source fared
subcult calendar sync [--force]Sync the configured CalDAV and iCal calendars into the cache
subcult agent usage [--json]Show the coding agents' token use today and this week, their pace and rate limits

Hardware

Hardware commands
CommandDoes
subcult hw apply [--target DIR]Write the hardware fixes' files (modprobe, initramfs, kernel command line); the installer runs it on the target sudo
subcult hw fixes [--all] [--json]List the hardware fixes this machine gets (--all: the whole catalogue)
subcult hw info [--json]Show the detected CPU, GPUs, radios, notes and matches
subcult hw match <text>Exit 0 when the product name or family contains the text
subcult hw matches [--json]Answer every hardware question (yes or no)
subcult hw packages [--all]List the firmware, microcode and GPU driver packages this machine needs (--all: every package it could pick)
subcult hw servicesList the system services the installer enables for this hardware
subcult gpu mode [intel|nvidia]Show or choose the desktop GPU for the next login (hybrid laptops)
subcult gpu run <command> [args...]Run one app on the NVIDIA GPU (PRIME render offload)
subcult thermal watch [--timeout <duration>]Print a JSON line for every trip point crossed, from the kernel's events
subcult thermal zones [--json]List the thermal zones and their trip points
subcult disk tpm enable | disable | statusUnlock the disk with the TPM instead of typing the passphrase sudo
subcult secureboot setupTurn on Secure Boot with this machine's own keys sudo asks first
subcult secureboot statusShow whether Secure Boot is on and boot files are signed
subcult setup fingerprint [remove]Enroll a fingerprint so the lock screen takes a touch, or remove yours sudo
subcult dell power probe | state [--json] | set <quiet|cool|balanced|performance> | charging set <adaptive|standard|express|primarily-ac|custom [START STOP]>Dell firmware power and charging profiles
subcult ht3 status <address> [--json]Show a connected TOZO HT3's battery and noise mode
