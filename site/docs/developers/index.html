Developers

The depth the other pages leave out. Each section ends at the file to read next; the repository is the full reference.

Repository

The top-level folders match the packaged tree in /usr/share, and each has a README.

Repository folders
cmd/, internal/Go commands (subcult, subarchy-setup, subcult-*) and the packages behind them
bin/subcult-* shell commands
shell/, lock/The desktop shell and the lock screen, in Quickshell
default/System defaults: Hyprland, SDDM, Plymouth, theme, shell setup, app catalogue
install/, iso/The installer, package lists and the archiso profile
migrations/Upgrade migrations
packaging/PKGBUILDs: subarchy, the keyring, Neovim, pinned AUR rebuilds
tools/Build, test, ISO, theme and site scripts
docs/Decision records, roadmap and plans, as an Obsidian vault

Pinned packages

The image carries packages Subarchy rebuilds from pinned sources: the Limine packages, Neovim with its plugins, the keyring. On a fresh checkout make iso stops with a line that starts build.sh: not in build/repo: and lists them. Build those in a clean container, then run make iso again:

$ packaging/aur/build.sh package …

CI does not rebuild them; it takes them from Subarchy's signed package registry. Read next: tools/iso/build.sh, packaging/aur/build.sh.

Unattended install

subarchy-install --config file --yes installs without questions. It wipes DISK, hence --yes. The config is KEY=value lines:

Install config keys
KeyValue
DISKWhole disk to wipe, such as /dev/vda. Required.
HOSTNAME, USERNAMERequired
USER_PASSWORD_FILEFile holding the user's password. Required.
LUKS_PASSPHRASE_FILEFile holding the disk passphrase. Required.
SUBARCHY_REPOpacman Server URL for the [subarchy] repository. Required.
TIMEZONESuch as America/Chicago. Default UTC.
LOCALE, KEYMAPDefaults en_US.UTF-8 and us
XKB_LAYOUT, XKB_VARIANTDesktop keyboard layout and variant. Default us, no variant.
OFFLINE1 to install from SUBARCHY_REPO alone
PACKAGE_CACHEA pacman cache folder to reuse
KERNEL_CMDLINE_EXTRAAppended to the kernel command line
WIFI_SSID, WIFI_PSK_FILEWi-Fi the installed system joins; no file for an open network

It makes a GPT disk with a 4 GiB ESP and a LUKS2 root, btrfs subvolumes @, @home, @log and @pkg, linux-zen and linux-lts as UKIs, Limine, snapper for @, and zram swap. Read next: the header of install/subarchy-install.

Shell keys and IPC

Keys reach the shell as Hyprland global shortcuts with the app id subcult, so a key press starts no process. The names: launcher-toggle, clipboard, alias.name, altswitch-next, altswitch-prev, altswitch-commit, brightness-up, brightness-down, capslock.

quickshell ipc -p /usr/share/subcult/shell show

That lists the IPC targets, such as subcult.launcher and subcult.osd. Tests and scripts use them; the key bindings do not. Read next: shell/README.md.

Extend the launcher

Launcher files
File in ~/.config/subcult/Holds
launcher/favorites.jsonThe favorites shown for an empty query: {"favorites": [desktop ids]}
launcher/aliases.jsonShort names for any item: {"aliases": {"up": "subcult update"}}
launcher/quicklinks.jsonWeb links and searches by keyword; {query} in the URL makes a search
launcher/snippets.jsonText the launcher types for you, with {date}, {time}, {clipboard}
commands/Executable scripts with a @raycast.title comment. Raycast script commands run unchanged.

Each alias is also a global shortcut. In ~/.config/hypr/hyprland.lua:

sub.bind("SUPER + ALT + U", "Update", sub.alias("up"))

Contributing

  • Bugs and ideas: GitHub issues (opens in a new tab).
  • Code: a pull request on GitHub against main. CI runs make verify, the package build and the shell tests; all must pass.
  • Design choices: the decision records (opens in a new tab). Read the relevant one before changing behaviour.
  • Security problems: report them privately through the repository's security tab (opens in a new tab).
  • These pages: sources in tools/site/pages/; tools/site/build.py writes site/.
