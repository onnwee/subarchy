{{Super}} is the Windows or Command key. The bindings live in default/hypr/bindings.lua; add your own in ~/.config/hypr/hyprland.lua.

Apps

App keys
{{Super+Return}}Terminal
{{Super+Space}}[[Launcher]]
{{Super+Shift+B}}Browser
{{Super+Shift+F}}File manager
{{Super+Ctrl+V}}Clipboard history

Windows

Window keys
{{Super+W}} or {{Super+Q}}Close
{{Super+F}}Full screen
{{Super+Alt+F}}Full width
{{Super+T}}Float or tile
{{Super+J}}Turn the split
{{Super+_arrow_}}Move focus
{{Alt+Tab}}Next window, most recent first
{{Alt+Shift+Tab}}Previous window

Workspaces

Workspace keys
{{Super+1}} to {{Super+0}}Go to workspace 1 to 10
{{Super+Shift+1}} to {{Super+Shift+0}}Move the window there
{{Super+S}}Show or hide the [[scratchpad]]

Mouse

Mouse bindings
{{Super+_left drag_}}Move a window
{{Super+_right drag_}}Resize a window

Capture

Screenshot and recording keys
{{Print}}Screenshot: drag a region, or click a window or display
{{Shift+Print}}Screenshot of a window
{{Ctrl+Print}}Screenshot of the display
{{Alt+Print}}Start or stop a screen recording
{{Alt+Shift+Print}}The same, with desktop and microphone audio

Screenshots go to Pictures and the clipboard; click the notification to annotate. Recordings go to Videos.

System

System keys
{{Power}}Lock. Holding it still powers off.
{{Super+Shift+Esc}}Log out
{{Super+/}}Display scale up
{{Super+Alt+/}}Display scale down
Closing the lidHandled by subcult display

Media

Media keys
Volume keysUp and down 5 %, with the [[OSD]]
Mute keysSpeaker or microphone
Brightness keysUp and down, with the OSD
{{Caps Lock}}Shows its new state in the OSD

These work at the lock screen too.

Launcher prefixes

Open the [[launcher]] with {{Super+Space}} and start the query with one of these. A plain query searches apps and subcult commands.

Launcher prefixes
TypeFinds{{Enter}}
=Calculator. Math in a plain query is answered too.Copies the answer
@Web search and quicklinks: @yt cats, @gh subarchyOpens the browser
.Files and folders under your home folderOpens the pick
:Emoji and symbolsCopies the pick
$Clipboard history, also {{Super+Ctrl+V}}Puts it back on the clipboard
  • A command with words after it passes them on: font set Iosevka.
  • Commands that change something important ask first: {{Enter}} runs, {{Esc}} goes back.
  • The last row of a search asks the default AI agent. That row sends your text off the machine, and says so.

Add your own

Bind keys in ~/.config/hypr/hyprland.lua, which [[Hyprland]] reads on top of the defaults:

sub.bind("SUPER + ALT + U", "Update", "subcult update")

Launcher aliases can have keys too. See [[developers#launcher]].
