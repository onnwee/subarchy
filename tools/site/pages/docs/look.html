One [[palette]] colours the shell, lock screen, terminal, Neovim, cursor, login screen, boot splash and boot menu.

Theme

[[Pult]] switches themes. It applies the palette to the shell, lock screen, terminal and Neovim straight away. The default theme is subcult-minimal.

Theme commands
pult apply nameApply a theme from Pult's catalogue
pult tuiBrowse and preview themes
pult doctorName the active theme
subcult cursor applyRedraw the cursor in the new palette
subcult theme apply-systemCarry the palette to the login screen, boot splash and boot menu. Asks for your password.
pult apply catppuccin-mocha

Back to the default:

pult apply -profile /usr/share/subcult/default/theme/subarchy.toml

Why a second command

The login screen ([[SDDM]]), boot splash ([[Plymouth]]) and boot menu ([[Limine]]) are system files. They change only when you run subcult theme apply-system.

Fonts

Three [[font roles]]: monospace, sans-serif and serif. GTK, Qt, the shell and the terminal all follow them.

Font commands
subcult font listThe curated fonts, what is installed, what each role uses
subcult font install nameInstall a curated font or any [[Nerd Font]]
subcult font set familyUse it for the terminal and shell; --ui or --serif for the other roles
subcult font import filesAdd font files you own, for your user
subcult font currentShow the family behind each role

Cursor

Subarchy draws its own cursor in a palette colour.

subcult cursor set --role lavender --size 24

Sizes are 24, 32 and 48. The colour is a [[palette role]]. Run subcult cursor apply after a theme change.

Display

Display commands
subcult display scale upAlso {{Super+/}}; down is {{Super+Alt+/}}
subcult display profile save nameSave the connected monitors' layout and workspaces
subcult display profile applyApply the saved layout that matches the connected monitors

Where settings live

Settings files
WhatFile
Your settings~/.config/subcult/
Palette~/.config/subcult/theme/palette.json, written by Pult
Bar layout~/.config/subcult/shell/bar.json, merged key by key over /usr/share/subcult/default/shell/bar.json
Keys and windows~/.config/hypr/hyprland.lua, on top of the defaults
Shell~/.zshrc or ~/.bashrc, after the first line
