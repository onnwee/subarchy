One command updates everything, and it takes a snapshot first.

Update

subcult update

In order: takes a [[snapshot]], upgrades packages, runs [[migrations]], cleans up.

Update commands
subcult update checkCount available updates without installing them
subcult update --dry-runShow what an update would do
subcult update migrate --pendingList migrations not yet run

The bar's updates widget shows the count too.

Channels

A [[channel]] decides where packages come from.

Update channels
ChannelPackages fromPick it when
stableA dated [[Arch Linux Archive]] snapshotYou want every machine on the same, tested package set. New installs start here.
edgeThe Arch mirrors, directlyYou want packages the day Arch ships them
subcult channel set edge

subcult channel shows the current one.

Undo a bad update

  1. Reboot. The [[Limine]] boot menu lists one entry per [[snapper]] snapshot.

  2. Boot the snapshot taken just before the update. subcult update made it for you.

Factory reset

The installer also leaves a read-only factory-reset snapshot of the fresh system.

If the shell crashes

The lock screen is a separate program from the shell. If the shell crashes it restarts, and the session stays locked.

Restart the shell yourself with systemctl --user restart subcult-shell.
