Subarchy is an Arch Linux desktop: [[Hyprland]] with its own shell, lock screen and theme, managed with one command, subcult. These pages are a reference. Look a thing up, then get back to work.

The same pages are on every install and work offline: run subcult help, or open Learn in the menu.

Quick start

  1. Download the ISO and check it. See [[install#download|Download]].

  2. Write it to a USB stick and boot from it, with Secure Boot off. See [[install#usb|Write the USB stick]].

  3. Answer the installer. [[subarchy-setup]] asks a few questions, then installs. See [[install#installer|The installer]].

  4. Log in. {{Super+Return}} opens a terminal, {{Super+Space}} opens the [[launcher]].

  5. Run subcult commands to see everything the system can do.

At a glance

What a new install has
Desktop[[Hyprland]] under [[uwsm]], with Subarchy's shell in [[Quickshell]]
Lock screenA separate program, so a shell crash cannot unlock the session
Disk[[LUKS2]] encryption, [[btrfs]] with zstd compression, [[snapper]] snapshots
Boot[[Limine]], one entry per snapshot, one [[UKI]] per kernel
HardwareFixes for known laptops and parts, applied at install. subcult hw fixes lists yours.
UpdatesThe [[channel|stable channel]], a tested Arch snapshot
PowerQuiet on battery: no avoidable polling, animation or GPU use. Nothing held back on mains.
Platformx86_64 with UEFI
