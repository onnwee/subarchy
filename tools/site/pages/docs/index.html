Subarchy is an Arch Linux desktop: [[Hyprland]] with its own shell, lock screen and theme, managed with one command, subcult. These pages are a reference. Look a thing up, then get back to work.

In development

There is no release and no downloadable image. The ISO builds in CI, installs in a virtual machine, and runs on one laptop. Everything here describes the source as it is today.

Quick start

  1. Build the ISO on Arch Linux. See [[install#build]].

  2. Install it into a VM with make install-test, or boot the ISO and let [[subarchy-setup]] walk you through it.

  3. Log in. {{Super+Return}} opens a terminal, {{Super+Space}} opens the [[launcher]].

  4. Run subcult commands to see everything the system can do.

What a new install has
Desktop[[Hyprland]] under [[uwsm]], with Subarchy's shell in [[Quickshell]]
Lock screenA separate program, so a shell crash cannot unlock the session
Disk[[LUKS2]] encryption, [[btrfs]] with zstd compression, [[snapper]] snapshots
Boot[[Limine]], one entry per snapshot, one [[UKI]] per kernel
UpdatesThe [[channel|stable channel]], a dated Arch Linux Archive snapshot
Platformx86_64 with UEFI
